Three kinds of page live here.

**[Guides](/docs/guides/account/)** are written for this site: how the FilmOpen account works, and how to write a plug-in for the app.

**[AI platforms and API keys](/docs/platforms/)** covers the platforms FilmOpen reaches models on — what they cost, and how to open an account and create a key for each. The app's *Settings → Provider keys* opens these pages.

**[Specifications](/docs/specifications/)** are the project format, the software and the agent layer. They are maintained with the application and appear here as **snapshots**: exact copies, each saying which version it is.

The documentation is a [public repository](https://github.com/filmopen-ai/filmopen-docs). If something here is wrong or missing, [a pull request](https://github.com/filmopen-ai/filmopen-docs/blob/dev/CONTRIBUTING.md) is the way to say so.
