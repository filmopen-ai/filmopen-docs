Plugin types: [Script Writers](../plugin-types/script-writers/).

**Parse Script is planned, and nothing in FilmOpen calls it yet.**

After FilmOpen imports a screenplay, a person may ask for *Parse Script*: it would propose story arcs as folders, scene breaks where times and places run together, and a synopsis of each scene, story arc and character. FilmOpen writes these only when the person applies them. FilmOpen's own import never waits for a plugin.

A later version fills in the prompts and the choice of models.
