# filmopen-docs

The public documentation site for [FilmOpen](https://filmopen.ai): the
specifications, the platform guides and the plug-in author's guide, built as a
static [Starlight](https://starlight.astro.build) site and served at
`docs.filmopen.ai`.

Two branches, each deployed on its own:

| Branch | Shows at | Holds |
|---|---|---|
| `dev` | `docs.dxv.filmopen.ai` | the documentation of the next release |
| `main` | `docs.filmopen.ai` | the documentation of the current one |

The specifications here are **snapshots**, imported byte for byte from the
application's repository and never edited in place; everything else is written
here. Contributions are welcome by pull request against `dev`.

The site itself lands in milestone 5.02, step 4. Until then this repository is
a placeholder with its branches and its rules in place.
